# Bill of Materials

| Component | Spec | Notes |
|---|---|---|
| Arduino Uno R3 | ATmega328P, ATmega16U2 USB chip | Gelek brand confirmed working |
| L298N Motor Driver | Dual H-bridge | |
| NEMA17 Stepper Motor | 17HS4401, 1.7A/phase | Coil pairs: Black-Blue, Green-Red |

## Wire

- 20-22 AWG stranded wire (silicone insulation preferred) for switch connections

## Connectors (optional)

- JST-XH 2-3 pin (for detachable switch connection to perfboard)
